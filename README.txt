Jarvis for Android (starter project, untested build)
1. Install Android Studio. File > Open > choose this folder. Accept Gradle sync / upgrade prompts.
2. Free Picovoice AccessKey: console.picovoice.ai
3. Phone: Settings > About > tap Build number 7 times > Developer options > USB debugging ON. Plug in, press Run.
4. In the app: paste both keys, tap buttons 1, 2, 3, then 4. Say "Jarvis".
Commands: open youtube | go back | go home | recent apps | open notifications | lock the screen | flashlight on/off | what time is it | anything else goes to Gemini.
